QuickTime Movie Help

If a QuickTime movie does not play even after installing the plug-in, try the steps below. These steps are provided for reference only. QuickTime movies may not play depending on your operating environment, such as the server's security status or client environment.

For Windows (in Internet Explorer 6.x)

From the Tools menu on the Internet Explorer menu bar, click Internet Options. Select the Security tab and click the Internet icon. Click the Custom Level button in the "Security level for this zone" area at the bottom of the dialog box. The Security Settings dialog box will appear. Under Run ActiveX controls and plug-ins, select Enable.

For Macintosh (in QuickTime Player 7.3)

Start the QuickTime Player application. From the menu bar, choose QuickTime Preferences. Click the Advanced tab and select Custom from the Transport Setup pop-up menu. Change the Transport Protocol to HTTP, and Port to 80.
